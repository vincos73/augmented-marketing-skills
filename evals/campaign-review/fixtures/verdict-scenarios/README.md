# Scenari sintetici per gli esiti

Questi tre casi brevi sono input autonomi e pubblicabili. Servono a verificare la distinzione tra `da correggere`, `pronta con condizioni` e `pronta`, che la fixture Brightpath pre-lancio non può mostrare perché contiene più blocchi contemporaneamente.

Ogni caso richiede una review della sola azione indicata. `responsabile da confermare` è una risposta valida quando i materiali non identificano una persona autorizzata.
