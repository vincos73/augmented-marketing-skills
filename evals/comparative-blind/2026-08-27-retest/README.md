# Retest mirato dell'eval comparativa cieca

Data: 2026-08-27

Questo retest riprende le stesse due fixture sintetiche e pubblicabili dell'eval iniziale, ma corregge i confondenti metodologici individuati nel primo report. Non modifica le skill e non contiene dati reali di Vincos.

Fonti riusate senza modifica:

- `../2026-08-27/fixtures/setup-business-context/`
- `../2026-08-27/fixtures/setup-marketing-system/`

Per ciascuna skill sono generate tre risposte:

1. baseline libera, senza skill e senza istruzioni aggiuntive di disciplina;
2. baseline source-disciplined, senza skill ma con una richiesta generica di tracciabilità, classificazione dei gap e controllo delle fonti;
3. risposta con la skill pertinente.

Ogni confronto è pairwise, cieco e controbilanciato: la risposta con skill viene confrontata separatamente con ciascuna baseline, con ordine A/B invertito.
